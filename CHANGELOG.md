# Changelog

## 0.3.0 — 2026-11-26

- Polished light/dark workspace, responsive menu, larger controls and reduced-motion-aware animations.
- Live grouped metric chart, certification ring, interactive relationship map and visual explanation of the semantic layer.
- Global vocabulary search, advanced tool requests, CSV/JSON export, result-table filtering and readable evidence.
- Validation, MCP connect, audit, settings and administrator authoring screens.
- Live schema validation, isolated graph preview, source mapping preview, diff and explicit certification.
- Durable certified source snapshots, restart recovery, stale-revision protection and single-writer publication.
- Structured API errors, bounded audit history, request timeout/cancellation and offline recovery.
- Responsive axe checks, screenshot regression baselines, Lighthouse and static bundle quality budgets.
- Beginner documentation, real screenshots, deployment boundaries and baseline audit.

No public semantic tool was renamed and the ontology format remains compatible. MCP remains stdio;
each launched MCP process reads its selected snapshot. English is available; Urdu is scaffolded only.
Single-process storage, small uploads and operator-managed retention remain explicit limits.
