# OntoLayer 0.3 verification

## What changed

The release adds a polished responsive workspace, light/dark/system themes, subtle reduced-motion-aware
animations, live grouped metrics, certification visualization and a visual explanation of the semantic
layer. The relationship map supports focus, neighbors, status filtering, zoom, pan and keyboard access.
Search, advanced tool requests, result exports, validation, MCP setup, audit and settings are available.

Administrators can edit/import a definition, run live schema validation, preview a fully validated graph,
review source mappings and a diff, and explicitly certify. The server saves certified source snapshots,
rejects stale revisions and restores its active snapshot after restart. Semantic APIs and ontology format
remain compatible. The original baseline audit is in [audit-v0.3.md](audit-v0.3.md).

- Exact local startup: `.\scripts\dev.ps1 -m ontolayer serve --ontology examples/retail/ontology.yaml --credentials examples/retail/credentials.yaml --demo`.

The [GitHub workflow](https://github.com/AshubShafqat/ontolayer/actions/workflows/ci.yml) additionally checks

Lighthouse and container startup with a governed query. Release publication is gated on successful CI.
Docker is not installed on the development machine; Linux CI supplies the container verification.

## Operating limits

- One writer process per workspace directory; no clustered graph or multi-worker publication protocol.
- In-memory graph and bounded current-process audit view; durable certified snapshots and audit files
  need operator-managed backups, retention, disk quotas and restore procedures.
- Administrator editing is a document editor, not a visual schema designer. JSON/YAML imports are
  supported; Turtle is structural export only.
- CSV upload is bounded to 48 KB/1000 rows, and requests to 64 KiB. Data ingestion is not streaming.
- MCP is local stdio. Its independently launched process uses its selected snapshot until restarted.
- No OIDC, public-host provisioning, high-availability deployment, document extraction or external
  penetration test is claimed. Public demo credentials must never be used with private data.
- English is implemented; Urdu/RTL scaffolding is not a completed translation. Browser pinch zoom
  works; the graph does not implement a separate custom two-finger gesture.
- Automated axe/screenshot checks supplement rather than replace assistive-technology/user research.
