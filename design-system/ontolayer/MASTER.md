# OntoLayer application design

Direction: a restrained data workspace, using the design skill's Minimalism / Swiss guidance.
The search's marketing-page structure is not applicable to this operational application.

- Dark ink sidebar, warm light canvas, white surfaces, indigo primary action and teal status.
- System sans-serif fonts; no remote fonts or other required third-party browser requests.
- Clear hierarchy: workspace eyebrow, page title, short explanation, data or controls.
- Compact bordered cards, generous page gutters, 8px spacing rhythm, 12px corner radius.
- Visible keyboard focus, explicit labels, semantic buttons, status text in addition to color.
- Tables scroll within their card; a compact collapsible navigation menu appears on mobile.
- 18px card radius, clear typographic hierarchy, restrained indigo/teal accents and muted blue canvas.
- Visual explanation cards connect sources, meanings, policies and agent answers.
- Grouped metrics and certification rings derive from authorized data only.
- Directed, color-coded concept graphs support focus, neighbors, zoom and pan.
- Short transform transitions and slow edge-flow animation respect reduced-motion preferences.
- No fabricated performance charts, popularity counters, or unsupported certification claims.
- Every user-facing metric comes from the authenticated semantic API.
